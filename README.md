# calculator
==============================================================

In this project I will use array methods and objects to build
a calculator where yoiu can insert more complex formulas.

I will do this by using an array to collect every single keyboard
input. Then I will evaluate the the input by scanning for
non-working input like various signs and letters.

after that, i will join the array as a string and then I will
convert it to an integer.

as soon as this part of the calculator works, I will use objects
to add a few other functions to the calculator. More TBA.
